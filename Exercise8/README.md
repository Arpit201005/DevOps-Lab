# Exercise 8: Hello World CI Job Using Jenkins

## 1. Objective

To understand the basics of Continuous Integration (CI) by creating a shell script, storing it in a GitHub repository, and configuring a Jenkins Freestyle project to retrieve and execute the script automatically during a build.

## 2. Technologies Used

- **Git and GitHub** – Version control and source code hosting.
- **Jenkins** – Automation server used to execute the build.
- **Bash Shell** – Executes the Hello World script.
- **Docker** – Runs the Jenkins server in a container.

## 3. Create the Hello World Script

A shell script named `hello-world.sh` was created inside the `Exercise8` directory.

### Script

```bash
#!/bin/bash

echo "Hello World!"
echo "This job is running through Jenkins."
echo "Build completed successfully."
```

The script prints messages to the console when executed.

## 4. Push the Script to GitHub

The script was added to the existing `DevOps-Lab` GitHub repository.

The following commands were used to stage, commit, and push the script:

```bash
git add Exercise8/hello-world.sh
git commit -m "Add Exercise 8 Hello World script"
git push origin main
```

The script is stored at:

```text
Exercise8/hello-world.sh
```

## 5. Ensure Jenkins Is Running

Jenkins was accessed through the web browser at:

http://localhost:8080/

The existing Jenkins Docker container was reused from the previous exercises.

## 6. Create the Jenkins Freestyle Job

A new Jenkins job named `HelloWorld` was created using the **Freestyle project** option.

### Source Code Management

The Git repository was configured with the following settings:

- Repository URL: `https://github.com/Arpit201005/DevOps-Lab.git`
- Branch to build: `*/main`
- Credentials: Not required for a public repository.

### Build Step

Under **Build Steps**, the **Execute shell** option was selected.

The following command was configured:

```bash
bash Exercise8/hello-world.sh
```

This command executes the script from the checked-out repository workspace.

## 7. Execute the Jenkins Job

The `HelloWorld` job was executed by clicking **Build Now**.

The build's Console Output was used to verify the execution of the shell script.

Expected output:

```text
Hello World!
This job is running through Jenkins.
Build completed successfully.
Finished: SUCCESS
```
